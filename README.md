# Handy 🖐️

> My very first passion project—a web app that bridges computer vision and interactive web interfaces to create, crop, and edit photos using hand gestures!

---

## 📖 About The Project

**Handy** is an exploratory project created to challenge myself in both front-end and back-end development. As someone expanding my technical toolkit, I used this project to dive hands-on into **Computer Vision** for backend logic while building a functional **HTML** interface—leveraging AI assistance to accelerate the learning process and solve implementation challenges.

With **Handy**, users can interactively control photo capture and manipulation through hand gestures: crop photos with your fingers, capture them, place them onto an interactive canvas, edit your composition, and enjoy your personalized creation!

---

## ✨ Key Features

*   ✌️ **Gesture-Based Cropping:** Crop photos intuitively using finger gestures via real-time computer vision tracking.
*   📸 **Gesture Photo Capture:** Capture frame
*   🎨 **Interactive Canvas:** Place captured photos directly onto a canvas workspace.
*   ✏️ **Photo Editing:** Adjust and refine your image composition right in the browser.
*   🖼️ **Export & View:** Enjoy and export your final edited visual creation!

---

## 🛠️ Built With

*   **Back-End & Vision:** [Python](https://www.python.org/) (Computer Vision logic & gesture tracking)
*   **Front-End:** [HTML](https://developer.mozilla.org/en-us/docs/Web/HTML) / Web Canvas (User Interface & layout)
*   **AI Assistance:** Utilized for conceptual guidance, debugging, and learning full-stack integration patterns.

---

## 🚀 Key Learnings & Takeaways

*   **Computer Vision Integration:** Learned how to process real-time webcam streams and translate hand landmarks into UI coordinates.
*   **Full-Stack Bridge:** Connected Python-driven backend computer vision capabilities with a web front-end interface.
*   **AI-Driven Learning:** Accelerated my understanding of new frameworks and rapid prototyping through AI-assisted workflows.
